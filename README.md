# Mini-Project-DDP

Nama: Efraim Juniar Tonda Kala'

NIM: 2609116064


Program ini dibuat menggunakan bahasa pemrograman Python, dan berfungsi untuk membantu pendaki mencatat satwa yang mereka temui selama perjalanan mendaki gunung, dengan tampilan berbasis teks yang sederhana. Ada beberapa pilihan menu yang tersedia, yaitu menambah data satwa, menampilkan seluruh data yang tersimpan, mengubah data yang sudah ada, serta menghapus data yang tidak diperlukan lagi. Pada contoh yang ditunjukkan, pengguna memasukkan data satwa berupa nama, jumlah individu, dan ketinggian lokasi tempat satwa itu ditemukan, kemudian program secara otomatis memeriksa apakah satwa tersebut termasuk jenis yang dilindungi dan menentukan zona habitatnya berdasarkan ketinggian yang diinput tadi. Setelah data berhasil disimpan, program dapat menampilkan kembali seluruh informasi tersebut dengan tampilan yang tersusun rapi. Secara keseluruhan, program ini tidak hanya berfungsi sebagai pencatat data biasa, tetapi juga memberikan informasi tambahan yang bermanfaat terkait status perlindungan satwa yang ditemukan selama pendakian.
